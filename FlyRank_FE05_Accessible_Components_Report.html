1. Executive Summary & The "Why It Matters" Thesis

AI assistants generate UI components at remarkable speed, but they generate inaccessible markup just as fast. An engineer cannot competently review, critique, or supervise AI-generated frontends without a first-principles understanding of accessible DOM primitives. FE-05 addresses this competency by constructing three core interactive components completely by hand in React 19 + TypeScript without third-party component libraries:

  • Modal Dialog (playground/Modal.tsx): W3C dialog pattern with strict focus trapping (Tab / Shift+Tab), Escape dismissal, and focus restoration to the trigger element.
  • Tabs Widget (playground/Tabs.tsx): W3C tabs pattern with roving tabIndex (0 active, -1 inactive), arrow key cycling, and Home / End navigation.
  • Disclosure (playground/Disclosure.tsx): W3C disclosure pattern using a native button trigger with aria-expanded and aria-controls linked to an expandable role="region".

3. Concrete Gaps Identified: Custom Hand-Crafted Code vs. shadcn/ui

As documented in NOTES.md, an architectural source review of shadcn/ui (powered by Radix UI primitives) revealed key production concerns handled by battle-tested libraries:

Gap 1: Portal Rendering & Stacking Context Isolation

Our custom modal renders inline within the parent component's DOM tree. If any ancestor element has overflow: hidden, transform, or filter, the browser creates a new stacking context that traps fixed-position children. Shadcn/ui renders dialogs via @radix-ui/react-portal directly into document.body, preventing z-index clipping.

Gap 2: Scroll Locking & Layout Shift (CLS) Compensation

Our modal traps keyboard focus but allows background mouse wheel scrolling. Shadcn/ui utilizes react-remove-scroll to lock document.body scrolling and dynamically injects padding-right matching the browser scrollbar width (window.innerWidth - document.documentElement.clientWidth), preventing jarring 15px layout shifts.

Gap 3: Screen Reader Sibling Isolation (aria-hidden / inert)

While our focus trap prevents Tab navigation outside the modal, screen reader virtual cursors (VoiceOver/NVDA swipe navigation) can escape inline modals. Radix dynamically traverses the DOM and applies aria-hidden="true" (or native inert) to all sibling nodes outside the dialog container.
