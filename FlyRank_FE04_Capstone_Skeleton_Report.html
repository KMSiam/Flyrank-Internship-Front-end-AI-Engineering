1. Executive Summary & "Deploy on Day One" Philosophy

In professional software engineering, deployment is not a postponed finale—it is the foundational pulse of development. FE-04 establishes the full architectural skeleton for the Frontend AI Capstone Platform, deployed on day one so that every subsequent commit lands on a verified live preview environment.

Built with Next.js 15 App Router, React 19, and Tailwind CSS, the application strictly adheres to the modern paradigm: Server Components by default, isolating Client Components only where user interactivity (such as streaming chat, mobile drawer toggles, and dynamic form inputs) is explicitly required.

Evaluation Criteria Satisfied: Preview builds cleanly with zero errors (12/12 routes compiled in 3.5s) • Every screen in the specification exists as a routed placeholder • Responsive at 375px mobile and 1280px desktop • Zero secrets committed with .env.example and strict .gitignore • Server Component /health renders fetched data.

3. Base Design Tokens & Viewport Responsiveness

Mobile Viewport: 375px (iPhone SE / Small Screen)

• Hamburger navigation toggle opens a dedicated mobile drawer with touch-friendly 44px hit targets.
• Grid layouts collapse to single-column (grid-cols-1) to prevent horizontal scrolling.
• Text scales responsively (e.g. text-2xl sm:text-3xl) ensuring visual hierarchy.
• Overflow-x is globally clamped with responsive touch padding.

Desktop Viewport: 1280px (Standard Monitor)

• Persistent horizontal navigation header with active route border pills.
• Multi-column workbench grid (grid-cols-3 and grid-cols-4) for high information density.
• Fixed telemetry headers and real-time inference latency indicators.
• Zero Cumulative Layout Shift (CLS) during page hydration.

5. Zero-Secrets Invariant & Environment Governance

Security is maintained as an unbending constraint. The repository adheres to strict credential isolation:

  • .env.example Committed: Outlines required public parameters (NEXT_PUBLIC_APP_URL, NEXT_PUBLIC_TELEMETRY_ENDPOINT) and safe placeholders for server-side inference keys (AI_PROVIDER_KEY="sk-antigravity-placeholder-key-xxxxxxxx").
  • .gitignore Enforced: Strictly ignores .env, .env*.local, .vercel, and all temporary credential files. Real keys are supplied exclusively via Vercel/Netlify Dashboard Environment Variables.
