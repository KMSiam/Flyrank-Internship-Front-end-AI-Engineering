1. Project Brief & Real-World Problem

The FlyRank Frontend AI Engineering Capstone is an enterprise-grade autonomous SEO and prompt intelligence platform. Conventional AI wrappers suffer from layout shifts, unformatted raw JSON dumps, sluggish chatbot loops, and zero keyboard or screen-reader accessibility. FlyRank solves this through a unified Next.js 15 App Router architecture that combines real-time Server-Sent Events (SSE) token streaming with polite screen-reader announcements (aria-live="polite"), schema-driven Generative UI rendering 4-state tool lifecycles (streaming input, input available, structured score cards, and graceful error boundaries), interactive 3D WebGL Neural Node staging on Three.js r170, and a custom fullscreen GLSL Quantum Aurora shader hero.

4. Production Hygiene & Abuse Protection

Operational Guardrails (Signed Off)
  • Streaming Ceiling: export const maxDuration = 30; prevents serverless edge connection hangs.
  • Sliding Window Rate Limiter: Enforces 30 requests/minute per client IP with HTTP 429 Too Many Requests and dynamic Retry-After headers.
  • Input Character Capping: Limits prompts to 4,000 characters with HTTP 413 Payload Too Large to protect against credit exhaustion.
  • Deterministic Fallback: If external keys are omitted, a high-fidelity simulator streams tokens without throwing 500 errors.

5. Engineering Reflection Summary

Hardest Problem: Bridging the asynchronous impedance match between high-frequency streaming LLM tokens (emitted every 30ms) and screen-reader synthesis. Applying aria-live="polite" inside a dedicated landmark region allowed calm auditory synthesis without speech loop locks.

Key Surprise: Fullscreen WebGL shaders quickly overheat mobile GPUs if DPR is unconstrained. Capping devicePixelRatio to 2.0 and adding a visibilitychange pause handler reduced battery consumption by ~70% while maintaining flawless 60 FPS rendering.
