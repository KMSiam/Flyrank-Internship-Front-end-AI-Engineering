1. Six-State Micro-Interaction Choreography

The component avoids abrupt swaps by guaranteeing that every state change is a mathematically continuous transition:

State Visual Treatment Motion & Property Transition Duration & Easing
1. Idle Brand color, crisp icon + label, subtle shadow Baseline position, scale: 1.0, opacity: 1.0 Default resting state
2. Hover / Focus White/10 highlight sheen, visible focus ring Subtle scale micro-lift, focus ring offset 2px 150ms ease-out
3. Active / Click Tactile depth depression scale(0.98) on mouse down 100ms ease-in
4. Loading Spinning loader replaces icon, label updates Label translates, spinner smoothly fades in (opacity 0 → 1) 200ms ease-out
5. Success Emerald green badge, checkmark icon Checkmark scales to 1.1; auto-reverts to idle in 1.8s 200ms ease-out
6. Error Rose red badge, retry icon, physics shake Horizontal keyframe shake (translateX ±4px), persists for retry 350ms cubic-bezier

2. Duration & Easing Rationale (Why these choices?)

1. Fast 200ms Window

Human perceptual reaction time averages 150–250ms. An interaction transition of 200ms feels snappy and immediate to power users without jarring the visual cortex.

2. ease-out Landing

Standard transitions use ease-out so the change initiates with urgency and decelerates smoothly into place, creating physical authenticity.

3. Physics-Based Shake

The error state uses cubic-bezier(0.36, 0.07, 0.19, 0.97) over 350ms to simulate the physical damping of an elastic spring when rejecting an input.

4. Compositor Performance & Reduced Motion Guarantees

  • Zero Layout Thrash: Transitions animate exclusively transform and opacity. No height, width, margin, or layout recomputations occur (CLS = 0.00).
  • Interruptible Lifecycle: Spam-clicking during in-flight transitions is safely locked via debounced state guards without dropping event handlers or leaking timeouts.
  • prefers-reduced-motion: Under motion-reduce, all transforms and keyframe shakes are completely eliminated via motion-reduce:transform-none and motion-reduce:animate-none, while retaining vital color and text feedback.
  • Keyboard & Screen Readers: Visible focus-visible:ring-2 focus ring and aria-live="polite" ensure instant accessibility for keyboard and screen reader users.
